# Track geometry sources

`Catalunya.csv` and `Silverstone.csv` are adapted from the TUMFTM racetrack database at commit `e59595d1f3573b30d1ded6a08984935b957688e0`:

- <https://github.com/TUMFTM/racetrack-database/blob/e59595d1f3573b30d1ded6a08984935b957688e0/tracks/Catalunya.csv>
- <https://github.com/TUMFTM/racetrack-database/blob/e59595d1f3573b30d1ded6a08984935b957688e0/tracks/Silverstone.csv>

The source project says its centerlines were fetched from OpenStreetMap and smoothed, widths were extracted from satellite imagery, and source accuracy varies by circuit. They are suitable for geometry and racing-line algorithm checks, not as a precision survey or proof of a current circuit layout. The raw source files and LGPL-3.0 license are retained in this directory. Derived track fixtures must preserve this attribution and license notice.
